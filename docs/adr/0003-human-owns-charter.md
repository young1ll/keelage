# 0003. 사람은 하네스(차터)의 소유자이지 하네스가 아니다
Status: accepted · Date: 2026-09-10
## Context
사람이 매 변경을 판단하면 병목이 된다. AGI·자율 개선이 와도 남는 역할은 의도·경계·책임이다.
## Decision
자율 수준 L0~L3을 범위·제약별 속성으로 둔다. 하네스는 판단에서 컴파일(승격)되며 승격 규칙은 원천 판단과 사람이 읽는 설명 문단을 가진다. 사람 개입률 하락은 성숙 지표다. 대외 용어는 Charter.
## Consequences
Change 애그리게이트는 하네스 변경을 항상 L0으로 강제한다. 강등은 회귀 1회 자동, 재승격은 이력 재축적.
