# 0007. 온톨로지는 동작을 바꾸는 요소만 허용한다
Status: accepted · Date: 2026-09-10
## Context
문서화 온톨로지는 실패했고 Foundry의 운영 온톨로지는 성공했다. 차이는 행동 결합이다.
## Decision
고정 온톨로지(타입 8·관계 6). 확장은 v2 플러그인으로, 검사기·영향 의미·라우팅 효과를 코드로 함께 등록해야 한다. 모델링 UI 비목표. 대외 서사에 '온톨로지'를 앞세우지 않는다.
## Consequences
닻·소유·충돌·승격은 코드·커밋·판단에서 자동으로 채워져야 한다(포워드 디플로이 비용 없음).
