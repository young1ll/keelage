# 0004. 책임 원장은 투명성 로그 구조를 쓴다
Status: accepted · Date: 2026-09-10
## Context
무결성·진정성·존재 시점·완전성·절차 준수를 제3자가 검증해야 한다. 블록체인·ZK가 거론됐다.
## Decision
rfc6962 머클 트리 + 서명 체크포인트 + 포함/일관성 증명(서버 원장만). 이벤트는 meta/body 분리 해시. TSA·증인은 플러그인, 블록체인은 체크포인트 앵커링 옵션, ZK는 비목표(선택적 공개로 대체).
## Consequences
`verify-proof` CLI를 공개해 서버를 믿지 않고 검증 가능해야 한다. 데몬 원장은 해시 체인으로 충분.
