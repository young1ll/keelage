# 턴 분류 재현율 (8주차부터, dogfood)

계획서 §3.4: "측정: dogfood 3개월 동안 수동 라벨 표본으로 재현율 기록". 스펙 §1: 재현율이 낮아도 된다 — 같은 닻 3회 규칙이 흡수.

## 정의
- 분류기: `supply.ClassifyPrompt`(redirect)·`supply.IsRevertCommand`(revert), 나머지 accept. 규칙은 ADR 0013.
- 표본: 매주 세션 20턴을 사람이 라벨(accept/redirect/revert). 원문은 이 문서에도 적지 않는다 — 라벨과 패턴 이름만.
- 재현율 = 사람이 redirect/revert로 라벨한 턴 중 분류기도 그렇게 본 비율. 정밀도도 같이 적는다.

## 기록

|---|---|---|---|---|
| 8 | 단위 테스트 표본(한·영 12/7 문장) | 12/12 · 7/7 | 8/8 · 8/8 | 실세션 표본은 훅 설치 후부터 |

## 알려진 한계
- "rather"·"no" 단독은 잡지 않는다(오탐 방지). "그냥 …"류 완곡한 방향 수정은 못 잡는다.
- 되돌리기는 git 명령만 본다. 에디터의 undo·Edit로 원복한 경우는 못 잡는다(내용 비교는 v1).
